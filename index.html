⚙️ Налаштування

🔐 MQTT-підключення

Збережені дані V21 підхоплюються автоматично. Підключення не надсилає команд пристроям.

Підключення автоматичне: після першого введення дані зберігаються, а MQTT відновлюється при відкритті додатку та поверненні мережі.

Паролі MQTT, Wi-Fi та PIN воріт зберігаються лише на цьому пристрої, у сховищі браузера без шифрування. Повторно вводити їх не потрібно. У GitHub вони не потрапляють.

Повний доступ до налаштувань

Локальний шлюз не підключений.

V36.1 приймає основні команди через MQTT. Для розкладів, герконів і налаштувань потрібен шлюз у домашній мережі — він входить до вихідного проєкту. Працює через ваш брокер, без відкривання портів роутера.
