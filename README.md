# Староміська 78а — віддалений пульт V1.0

Вебінтерфейс для ESP32-S3 Garden_U_V35.9 FAST START через EMQX Cloud MQTT over WSS.

## Установка на GitHub Pages

Замініть у корені репозиторію попередні `index.html`, `app.js`, `style.css` цими трьома файлами. `README.md` можна замінити теж. У GitHub Pages залиште `main` / `(root)`.

## Робота

Відкрийте GitHub Pages, введіть MQTT-пароль та натисніть «Підключитися». Пароль не записується до localStorage або GitHub. Стан ESP32 надходить через `garden/controller/state` та `garden/controller/availability`.

Команди з V35.9: `light/{1..3}/set` (`ON`, `OFF`), `water/{1..4}/set` (`START`), `water/stop/set` (`STOP`), `boiler/mode/set` (`AUTO`, `OFF`), `boiler/setpoint/set` (5–30 °C), `boiler/setpoint/reset`. Усі команди публікуються з `retain:false`. Ручний запуск поливу й зміна опалення вимагають підтвердження. Вебпульт не замінює місцеву автоматику та захист обладнання.

**Увага:** публікація MQTT повідомлення не дорівнює підтвердженню фізичного виконання. Нове повідомлення `state` підтверджує лише отримання актуального стану, а не саме прийняття конкретної команди. Якщо потрібні строгі ACK, це вимагає окремого механізму у прошивці.

**Безпека:** GitHub Pages — публічний сайт. Для реального використання бажано створити окремий MQTT-користувач з мінімальними ACL та не ділитися паролем. Вебінтерфейс не зберігає пароль на диску, проте він існує в пам'яті вкладки протягом сеансу. MQTT WSS захищає передачу TLS.
