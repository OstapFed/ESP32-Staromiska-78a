# Староміська 78а — вебпульт V17

Оформлення за наданим знімком локальної панелі ESP32-S3: зелена верхня смуга, компактна панель по центру, сад із деревом, пагорбами й місяцем, показники часу та температури, шість темних плиток меню з кольоровими значками. На вузькому екрані меню має дві колонки.

## Встановлення
Розпакуйте ZIP і завантажте index.html, style.css, app.js та README.md у корінь ESP32-Staromiska-78a замість попередніх файлів. Натисніть Commit changes. Прошивати ESP32-S3 не потрібно. Версія V17 зазначена внизу; посилання на CSS/JS оновлені для обходу кешу.

## Логіка
MQTT-команди, захист від застарілих даних, очікування підтвердження температури та погода збережені. У JavaScript додано лише дублювання годинника у верхній смузі. Це зміна дизайну; проблему непідтвердженої уставки вона не виправляє.

Показник «Надворі» — Open-Meteo; кімнатна температура надходить від ESP32. Пароль MQTT вводиться в Налаштуваннях, не записаний у файлах.
