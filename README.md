# Староміська 78а — вебпульт V18

Перед кнопкою «Підключитися» додано «Зберегти налаштування».
Зберігаються WSS-адреса, користувач і пароль MQTT у localStorage цього браузера на цьому пристрої. При повторному відкритті поля заповнюються автоматично. Підключення запускається вручну; збереження саме по собі не підключає до MQTT і не надсилає команд обладнанню.

Пароль зберігається локально без шифрування: користуйтеся цією опцією на власному пристрої. У ZIP та GitHub вашого пароля немає. Дані не переносяться автоматично між браузерами/пристроями й можуть зникнути після очищення даних сайту або закриття приватного режиму.

«Видалити збережені дані» видаляє запис і очищає поле пароля, але не перериває активне MQTT-підключення. «Відключитися» зупиняє підключення, зберігаючи введені поля. Якщо сховище заблоковано, ручне підключення залишається доступним.

Для встановлення замініть чотири файли в корені GitHub-репозиторію: index.html, style.css, app.js, README.md. Натисніть Commit changes. Після публікації внизу пульта має відображатися V18. ESP32-S3 перепрошивати не потрібно.

Дизайн V17 та логіка керування обладнанням збережені. Це оновлення не є виправленням непідтвердженої зміни уставки.
