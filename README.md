# Староміська 78а — віддалений вебпульт V1.1

Оновлено під локальний стиль ESP32-S3: зелена шапка, меню з 6 розділів, кольорові кнопки.

## Виправлення температури
Кнопки ±0,5 °C **без діалогу підтвердження**. Після натискання вебпульт надсилає `garden/controller/boiler/setpoint/set` (наприклад `20.5`) і чекає фактичний `boiler_setpoint` у `garden/controller/state`. Поки очікує, кнопки заблоковані й показується цільова температура. Якщо ESP32 не підтвердить її протягом 18 секунд, показується повідомлення про помилку і остання фактична уставка. Публікація до брокера НЕ є підтвердженням виконання.

## Інші команди
Освітлення `garden/controller/light/{1..3}/set` (`ON` / `OFF`); полив `garden/controller/water/{1..4}/set` (`START`), зупинка `garden/controller/water/stop/set` (`STOP`); котел `garden/controller/boiler/mode/set` (`AUTO` / `OFF`), повернення розкладу `garden/controller/boiler/setpoint/reset` (`RESET`). MQTT retain=false. Запуск поливу та вимкнення котла залишаються з підтвердженням з міркувань безпеки.

## Розгортання
Розпакуйте архів і завантажте `index.html`, `style.css`, `app.js`, `README.md` у корінь публічного репозиторію GitHub Pages замість попередніх файлів. Не завантажуйте ZIP як є. Після GitHub Pages deployment оновіть сторінку Safari. Пароль MQTT вводиться в меню «Налаштування», не зберігається у GitHub чи localStorage.

**Обмеження:** вебпульт відтворює основний стиль і доступні MQTT-функції локальної панелі. Редагування локального розкладу поливу й усі локальні меню без окремих MQTT API не дублюються. Не змінює прошивку ESP32-S3. Якщо зміна температури не підтверджується, потрібна перевірка MQTT журналу/обробки команди на ESP32, а не лише інтерфейсу.
