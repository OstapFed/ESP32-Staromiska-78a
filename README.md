# Староміська 78а — вебпульт V19

Пароль MQTT, користувач та WSS-адреса автоматично зберігаються після першого успішного підключення. Достатньо ввести пароль і натиснути «Підключитися». При повторному відкритті в тому самому браузері поля відновлюються; підключення залишається ручним. Кнопка «Зберегти налаштування» також працює.

Запис перевіряється зворотним читанням localStorage. Якщо браузер блокує сховище, пульт показує повідомлення, але дозволяє підключення. Збереження V18 сумісне з V19. Невдале підключення не перезаписує попередній пароль. Видалення збережених даних не скасовується автоматичним перепідключенням MQTT.

Пароль зберігається локально без шифрування. Використовуйте власний пристрій. Дані можуть зникнути після очищення даних сайту або приватної сесії. Інший браузер чи телефон має окреме сховище. Публічність репозиторію не впливає на це.

## Оновлення
Замініть index.html, style.css, app.js, README.md у корені репозиторію та натисніть Commit changes. Дочекайтеся публікації GitHub Pages. Унизу пульта має бути V19. Один раз введіть пароль і підключіться, після чого відкрийте сторінку повторно в тому самому браузері.

Прошивка ESP32 та MQTT-команди обладнання не змінені.
