# Староміська 78а — вебпульт V21

При кожному відкритті пульт відновлює збережені WSS-адресу, користувача й пароль та автоматично підключається до MQTT. Дані V18/V19 сумісні. Якщо збережених коректних даних немає, відкриваються налаштування: введіть їх один раз і натисніть «Підключитися».

Після успішного підключення дані зберігаються в цьому браузері. При втраті мережі MQTT повторює з’єднання. Кнопка «Відключитися» скасовує також поточну спробу підключення й залишає пульт відключеним до ручного підключення або нового відкриття сторінки. Повернення до сторінки з кешу браузера відновлює попереднє активне з’єднання, але не скасовує ручного відключення.

Автопідключення лише підписується на дані — команд котлу, освітленню чи поливу не надсилає. Пароль зберігається в localStorage власного браузера без шифрування; не в GitHub. Видалення збережених даних вимикає автопідключення при наступному відкритті.

## Встановлення
Замініть 4 файли в корені GitHub-репозиторію, натисніть Commit changes та дочекайтеся публікації. Версія внизу — V21. Перепрошивати ESP32-S3 не потрібно.
