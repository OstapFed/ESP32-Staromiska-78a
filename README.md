# Garden Controller — додаток (PWA для iPhone і Android)

## 1. Хмарний брокер (безкоштовно)
1. Зареєструйтесь на HiveMQ Cloud, створіть Serverless-кластер.
2. Access Management → створіть двох користувачів: `esp32` (для контролера) і `phone` (для додатка).
3. Запишіть адресу кластера (xxxx.s1.eu.hivemq.cloud).

## 2. Контролер
Прошийте Garden_U_V35, відкрийте http://<IP>/remote:
- Віддалений доступ: увімкнути, TLS: так, перевіряти сертифікат: так
- Брокер: адреса кластера, порт 8883, користувач `esp32`, пароль
- Базовий topic: garden/controller
- Задайте пароль веб-інтерфейсу (також вмикає OTA), за бажанням ntfy topic і погоду.
НІКОЛИ не пробрасывайте порт 80 з роутера в інтернет.

## 3. Додаток
Викладіть папку на будь-який HTTPS-хостинг (GitHub Pages, Cloudflare Pages, Netlify).
- iPhone: Safari → Поділитись → На початковий екран.
- Android: Chrome → ⋮ → Встановити додаток.
У ⚙️ введіть адресу кластера, порт 8884 (WebSocket TLS), користувача `phone`, пароль.

## Push-сповіщення
Встановіть застосунок ntfy (iOS/Android), підпишіться на ваш topic.
