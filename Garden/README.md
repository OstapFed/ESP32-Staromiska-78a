# Garden для Android (Kotlin + Jetpack Compose)

Нативний додаток для контролера Староміська 78а. Керування й моніторинг через MQTT-брокер
(той самий, що в прошивці). Без сторонніх бібліотек для MQTT: власний клієнт на сокетах із TLS
(перевіряється сертифікат і ім'я хоста). Пароль брокера шифрується ключем Android Keystore.

**Що вміє**
- Опалення: температура, стан котла, уставка ±0,5 °C, режими Вимк / Ручний / Авто, «Відпустка», повернення до розкладу
- Кімнати (датчики Xiaomi): температура, вологість, батарея, зв'язок
- Графік температури й уставки (1 / 6 / 24 год), зберігається на телефоні
- Полив: запуск зон 1–4, зупинка, дощ, прогноз опадів
- Освітлення: 3 канали
- Налаштування брокера, інформація про контролер
- Автоперепідключення, «Контролер офлайн», «Дані застаріли»; світла/темна тема, динамічні кольори Android 12+

**Вимоги:** Android Studio (Koala 2024.1 або новіша), телефон з Android 8.0+ (API 26),
прошивка контролера **V35.8** або новіша.

## Збірка й встановлення
1. Android Studio → File → Open → оберіть папку `Garden`. Дочекайтесь Gradle Sync
   (потрібен інтернет; за запитом підтвердьте завантаження Gradle та Android SDK 34).
2. На телефоні: Налаштування → Про телефон → 7 разів торкнутись «Номер збірки» → Для розробників →
   увімкнути «Налагодження USB».
3. Підключіть телефон кабелем, оберіть його зверху в Android Studio, натисніть Run (▶).
4. Щоб отримати файл APK для встановлення без кабелю: Build → Build Bundle(s)/APK(s) → Build APK(s).
   Файл буде в `app/build/outputs/apk/debug/app-debug.apk`. Скопіюйте на телефон і відкрийте
   (дозвольте встановлення з невідомих джерел).

## Налаштування в додатку (вкладка «Налашт.»)
- Адреса: `v851c902.ala.eu-central-1.emqxsl.com`
- Порт: `8883`, TLS увімкнено
- Користувач і пароль: **окремий користувач для телефона**, створений в EMQX Cloud (Access Control → Authentication)
- Базовий топік: `garden/controller`
- Дозвольте цьому користувачу публікувати й читати `garden/controller/#` (EMQX → Authorization/ACL)

## Обмеження
- У фоні додаток від'єднується від брокера й оновлюється при відкритті. Для сповіщень (дощ, початок поливу,
  втрата датчика) встановіть застосунок **ntfy** і підпишіться на topic із налаштувань контролера (/remote).
- Код писався без Android SDK і не компілювався автоматично. Якщо Android Studio покаже помилку,
  надішліть її текст — її легко виправити.
- Швидкий варіант без збірки вже є: веб-додаток (PWA) з `garden-app.zip` встановлюється в Chrome
  («Встановити додаток»), але працює через WebSocket-порт брокера.
